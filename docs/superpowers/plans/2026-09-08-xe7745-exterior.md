# XE7745 Exterior Implementation Plan

> Execute in this session using the Superpowers test-first workflow; tightly coupled generation/integration tasks are handled inline, with independent final review.

**Goal:** Generate and integrate one reusable, validated XE7745 exterior GLB.

**Architecture:** Keep the existing repository/context/store, ModelAsset fallback and instance cloning. Procedural Blender geometry is visualization only. Export bottom-centered Y-up geometry; a small adapter centers it in the existing rack instance and moves only its cloned cover.

**Tech Stack:** Blender 5.2 Python, Python standard library, existing Three.js/R3F/TypeScript/Vitest.

**Spec:** `docs/superpowers/specs/2026-09-08-xe7745-exterior-design.md` (approved in chat).

## Constraints

- 482 × 899.56 × 174.3 mm; logical height 4U; front +Z in Three.js.
- Only exterior; no new internal hardware, rack/switch models or integrations.
- One GLB at the existing stable model path, target <50k triangles and <5 MB.
- Preserve the entirely untracked foundation; no blanket staging/commits or worktree migration.
